This guide gets you up and running with `py-sema` from installation to executing key CLI tools and building automated workflows.

## Prerequisites

Before installing `py-sema`, verify that your environment meets the following requirements:

- **Python**: Python `>= 3.11` and `< 4.0`
- **Package Manager**: [Poetry](https://python-poetry.org/) (recommended) or `pip`

## Installation

Install `py-sema` via Poetry or pip:

<CodeGroup>
```bash Poetry
poetry add pysema
```

```bash pip
pip install pysema
```

```bash From Source
git clone https://github.com/vliz-be-opsci/py-sema.git
cd py-sema
poetry install
```
</CodeGroup>

## Getting Started with CLI Tools

Once installed, `py-sema` registers CLI commands in your environment. Let's try common operations.

<Steps>
  <Step title="Discover Linked Data with sema-get">
    Resolve a subject URI, negotiate RDF MIME types, and output Turtle directly:

    ```bash
    sema-get https://data.emobon.embrc.eu/ -f turtle -o output.ttl
    ```

    You can also stream output directly to stdout with `-o -`:

    ```bash
    sema-get https://data.emobon.embrc.eu/ -f turtle -o -
    ```
  </Step>

  <Step title="Transform Tabular Data to RDF with sema-subyt">
    Generate RDF triples from a CSV file using a Jinja2 Turtle template:

    Create a template file named `person.ttl`:

    ```jinja2
    @prefix schema: <https://schema.org/> .
    @prefix ex: <https://example.org/person/> .

    ex:{{ id }} a schema:Person ;
        schema:name "{{ name }}" ;
        schema:email "{{ email }}" .
    ```

    With an input file `people.csv`:

    ```csv
    id,name,email
    1,Alice,alice@example.org
    2,Bob,bob@example.org
    ```

    Run `sema-subyt`:

    ```bash
    sema-subyt --templates . --name person.ttl --input people.csv --output output-people.ttl
    ```
  </Step>

  <Step title="Query Knowledge Graphs with sema-query">
    Query RDF files or SPARQL endpoints and output tabular CSV results:

    ```bash
    sema-query -s output-people.ttl -t all.sparql -o results.csv -f csv
    ```

    <Tip>
      Run `sema-query-templates` to install pre-built SPARQL templates for common vocabulary queries, SKOS concepts, and RDF predicate counters.
    </Tip>
  </Step>

  <Step title="Orchestrate Pipelines with sema-bench">
    To run multi-step workflows periodically or when files change, create a `sembench.yaml` file:

    ```yaml
    tasks:
      generate_rdf:
        func: subyt
        args:
          template_folder: ./templates
          template_name: person.ttl
          source: people.csv
          sink: people.ttl

      validate_shapes:
        func: shacl
        args:
          data_graph: people.ttl
          shacl_graph: shapes.ttl
    ```

    Run the pipeline with:

    ```bash
    sema-bench -c . -n sembench.yaml
    ```
  </Step>
</Steps>
